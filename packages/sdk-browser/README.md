# @crosslink/sdk-browser

<p align="center"><img src="https://crosslink.mintlify.site/crosslink.svg" alt="Crosslink" width="320" /></p>

The Crosslink SDK for browsers and installable PWAs, including the canonical pairing widget.

```bash
npm install @crosslink/sdk-browser
```

See the [Crosslink quickstart](https://crosslink.mintlify.site/quickstart) and [repository](https://github.com/jacobpowaza/crosslink).
