Crosslink Todo

An encrypted, peer-to-peer todo list. Add this app to your homescreen to get started.

1 Tap the Share button in your browser
2 Select "Add to Home Screen"
3 Open the app from your homescreen

Manual install

Your browser doesn't support automatic installation. To install manually:

iOS Safari: Tap Share > Add to Home Screen
Android Chrome: Tap menu (3 dots) > Add to Home Screen
Desktop: Click the install icon in the address bar

How will you connect?

Choose based on where your host is running

Simple

Same WiFi network

Phone and computer on the same local network. No internet needed. Fastest connection.

Anywhere

Any network

Works over cellular, remote, or different networks. Requires the host to have relay + signaling set up.

Pair with Host

Paste the pairing URI from the host CLI

Host Offline

The host is not reachable right now.

Troubleshooting

Local mode: Make sure the host is running and your device is on the same WiFi.

Relay mode: Make sure the host has started with signaling and relay services. Try generating a new pairing code on the host.
